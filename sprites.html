Sprite gallery

Every picture the game draws has a slot below. Drop a PNG named after the slot into assets/sprites/, list it in assets/sprites/manifest.json, and the game uses it instead of the code-drawn version. Anything you haven't painted yet keeps its code art.

Block guide: the exact PNG size, with the tile grid (32px = one tile), the footprint it stands on (solid box) and the anchor dot at the bottom centre. Current art: what the game draws today, for reference. Keep the transparent background and keep things standing on the bottom edge. See SPRITES.md for the full spec, and press B in the game to see the whole map as blocks.

Every slot also has a ready-to-paste image prompt (open "Image prompt" or press "Copy prompt"); they're all in PROMPTS.md too.

Sprite gallery

Every picture the game draws has a slot below. Drop a PNG named after the slot into assets/sprites/, list it in assets/sprites/manifest.json, and the game uses it instead of the code-drawn version. Anything you haven't painted yet keeps its code art.

Each template is the current art at the exact PNG size the game expects (2 image pixels per game pixel, so one tile = 32×32). Paint over it, keep the transparent background, and keep things standing on the bottom edge. See SPRITES.md for the full spec.
